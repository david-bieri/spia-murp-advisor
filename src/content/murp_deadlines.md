## How Jane should use this file

When a student asks "what's due this month?", "when does registration open?", "what are the thesis deadlines?", or any time-sensitive advising question, Jane should consult this file and give specific dates. Jane should note when a deadline is imminent (within 2 weeks) and recommend the student confirm dates directly with the Graduate School or their advisor, as dates can shift.

## Thesis milestone deadlines (sequence)

These are the standard milestones for thesis track students. Timing is approximate — advisor and committee chair set the actual dates.

| Milestone | Typical timing | Notes |
|---|---|---|
| Identify thesis committee chair | By end of semester 2 | Required before Thesis I registration |
| Form full committee (chair + 2 members) | Start of semester 3 | Required before Thesis I registration |
| Submit thesis proposal | Semester 3 (Oct/Nov for fall starters) | Must be approved by committee |
| Thesis proposal defense | Semester 3 | Committee vote required |
| IRB approval (if human subjects) | Semester 3 — allow 4–8 weeks | Start early; IRB processing can be slow |
| Data collection / fieldwork | Semester 3–4 | Varies by methodology |
| Draft chapters to advisor | Semester 4 (Jan–Mar) | Allow 4–6 weeks per chapter for feedback |
| Final draft to committee | 6 weeks before defense | Committee needs reading time |
| Thesis defense | Semester 4 (Mar–Apr) | Schedule room and committee availability early |
| Revisions and final submission | Within 2 weeks post-defense typically | Submit to Graduate School |
